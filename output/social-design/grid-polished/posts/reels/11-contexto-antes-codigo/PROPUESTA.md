# 11 · Dale contexto antes de pedir código

**Objetivo:** mostrar cómo preparar una petición de código verificable. **Formato recomendado:** reel de pantalla con comparación real, subtítulos y sin mostrar rostro. **Alternativa opcional:** 5 láminas basadas en el guion siguiente. **Portada:** [cover-11.png](../../../carousel-1080x1350/cover-11.png).

## Reel recomendado · 30–45 segundos

1. **0–5 s:** mostrar una petición ambigua en pantalla: «Haz un formulario».
2. **5–18 s:** añadir objetivo, entorno, restricciones y criterio de aceptación. Animar solo el resaltado de cada bloque; evitar chat falso.
3. **18–32 s:** enseñar una diferencia observable entre las dos respuestas de una prueba real. Acercar el texto clave, sin pretender que una sola comparación demuestra una mejora general.
4. **32–45 s:** mostrar una comprobación breve contra el criterio de aceptación. Cierre: «Contexto para pedir; pruebas para decidir».

**Audio:** subtítulos completos; voz de Sofía o clon de su propia voz solo si ella lo decide y revisa el resultado. Pantalla como protagonista. Un inserto corto del avatar estático puede aportar identidad, sin exigir labios o expresiones animadas. La portada 4:5 puede ser miniatura; el video requiere composición vertical propia.

**Producción:** si se muestran dos respuestas reales, generar ambas con el mismo entorno, guardar prompts completos y describir diferencias observables sin prometer mejora general ni porcentajes. No compartir datos privados.
